# README.md

## QR Code Generator for YouTube Link

This project generates a QR code for a YouTube video link using Python and the `qrcode` library.

### Files

- [`qr_code.py`](qr_code.py): Python script to generate the QR code.
- `youtube_qr.png`: Output image containing the QR code.

### Requirements

- Python 3.x
- `qrcode` library

Install the required library with:

```sh
pip install qrcode[pil]
```

### Usage

Run the script:

```sh
python qr_code.py
```

This will generate `youtube_qr.png` with the QR code for the YouTube link and display the image.

### Customization

To generate a QR code for a different link, edit the `website_link` variable in [`qr_code.py`](qr_code.py).
